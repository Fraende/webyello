# Vääntö Garage – WebYello demo 3

Kuvitteellinen korjaamo ja virityspaja. Staattinen sivusto: ei build-vaihetta, ei kolmansia osapuolia, ei evästeitä.

Tiedostot: index.html, varaus.html, tietosuoja.html, style.css, app.js, book.js, assets/ (kuvat webp, hero.mp4).
Esikatselu: `python3 -m http.server` kansiossa. Vercel: vedä kansio tai lisää repoon.

Huomioitavaa
- Kuvat ja hero-video on luotu tekoälyllä (Higgsfield, gpt_image_2 ja Seedance 2.5). Sivu kertoo tämän footerissa.
- Dyno-käyrät ovat havainnollistavia malleja, ei mittauksia. Sivu sanoo tämän.
- Varauslomake on demo: mitään ei lähetetä eikä tallenneta.
- Ei keksittyjä arvosteluja, asiakasnimiä tai lukuja. Tietosuojaseloste on esimerkkipohja.
- Fontit ovat järjestelmäfontteja (ei Google Fontsia), jotta ei synny kolmannen osapuolen pyyntöjä.
